Root cause

The ddos harness bootRealServer read TEST_PG_/TEST_REDIS_ env vars but .env.full-test exports HELIX_DATABASE_/HELIX_REDIS_ with different defaults (user helixcode vs helix, password helixcode_test_password vs helix, db helixcode_test vs helix_test). Fix

Moved envOr/envOrInt to always-compiled ddos_harness.go + added envOrHelix/envOrIntHelix helpers (HELIX_ first → TEST_ fallback → hardcoded default). Updated bootRealServer to use HELIX_ keys. 6 unit tests prove the 3-tier fallback.
