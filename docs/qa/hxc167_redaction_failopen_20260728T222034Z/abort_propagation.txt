# Abort-propagation proof — a failed scrub kills the CAPTURE SCRIPT

The library is SOURCED and callers run 'set -uo pipefail' WITHOUT errexit,
so a non-zero return is not sufficient: if the abort only killed a subshell
the capture would continue past a failed scrub and record a PASS.

```

recognizes it as intentional, non-secret content.

 The file has been REMOVED: it could not be certified free of
 credentials, and a transcript whose scrubbing status is unknown

 This is deliberately fatal. Redaction is the control that

 The offending value is NOT printed here (§11.4.10).
```
